# 混打邊界修正與驗證

本文件保留該階段的歷史結果；最新累積狀態與測試環境請見 [五輪組字選字修正](組字選字五輪檢查與修正_20260921.md)。本機證據路徑不隨 GitHub 發布，歷史程式行號以當時檢查快照為準。

## 原因與修正

英文精確詞區段原先以涵蓋長度選擇較長候選，沒有檢查與下一個中文音節的邊界。例如輸入 `automation` 接「能」的原鍵串 `s/6`，可能先固定為 `automations`，留下無法獨立轉字的 `/6`，導致整句混打合併失敗。

修正於共用混打解析器加入有界的邊界檢查：只向後看最多四鍵，在遇到明確聲調後沿用正式注音解析器，確認產生的音節在詞庫中有可顯示候選。相同終點只計算一次，避免重複解析。沒有聲調的英文尾端與未完成輸入維持原判定，沒有新增指定詞句的特殊規則。
