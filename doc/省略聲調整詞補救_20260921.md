# 省略聲調整詞補救（2026-09-21）

## 問題與修正

輸入「ㄑㄩㄒㄧㄠ」時，原本依第一聲精確查詢，找不到完整詞便組成「區消」。「取消」的詞庫讀音是「ㄑㄩˇㄒㄧㄠ」，因此缺少第三聲時沒有進入整詞排序。

新增通用的省略聲調召回：精確整詞不存在時，尋找音節相同、只需補足未標聲調的完整詞。沒有硬編碼「取消」或替換字串，也不增加詞庫特例。沿用既有介面、音節完成、選字及送出操作，認證與簽章身分保持不變。

| 輸入讀音 | 本次驗證結果 |
| --- | --- |
| ㄑㄩㄒㄧㄠ | 取消 |
| ㄑㄩㄒㄧㄠˋ | 取笑 |
| ㄑㄩˇㄒㄧㄠ | 取消 |
| ㄉㄧㄢㄋㄠ | 電腦 |
| ㄒㄧㄣㄎㄨ | 辛苦 |
| ㄑㄩˋㄒㄧㄠ | 去消；保留明確的第四聲 |

尚未完成的最後一個音節仍顯示注音；以原有 Space 完成音節或 Enter 送出時，套用整詞結果。這項補救不改變待完成音節的操作。

## 共用策略與限制

- 先保留精確解碼中的完整詞，只對剩餘連續單字區段比較補救候選，最長八個音節。
- 每個聲母、介音、韻母及已輸入的聲調都須相符；不做任意近音、鄰鍵或增刪音節猜測。
- 以既有詞頻與分詞結合度排序，每補一個聲調扣 120 分，並依詞頻加上低頻不確定性成本。補救路徑必須勝過逐字路徑，避免把「法＋貼」改成少見的「法帖」，或把「前＋要」改成專有名詞。
- 組字與候選窗使用同一組詞庫候選和評分；個人選字紀錄仍以實際輸入的讀音保存。來源按鍵、替換範圍、模型座標與人工選字鎖定保留。
- 精確單字查詢、反查及前綴查詢保持原規則。補救索引依系統詞讀音建立；完全新增、無對應系統讀音的個人詞仍依精確讀音使用。

詳細公式見 [候選與分詞計分](SCORING.md)。這是保守的省略聲調補詞，不保證任何未知注音都能推測出使用者的語意。
