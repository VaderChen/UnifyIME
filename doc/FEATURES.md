# 功能特色

## 中英連續輸入

- 標準注音鍵位與英文單字可在同一段文字中連續輸入。
- 中英文採獨立詞庫；混打候選保留語言與替換範圍資訊。
- 支援未完成英文前綴、完整英文單字及多次語言切換。
- 數字鍵盤的數字與運算符號使用獨立鍵碼，不混入主鍵盤注音映射。

短英文與有效注音鍵序重疊時，保留中文輸入路徑，英文仍可由候選選取。此規則依詞庫與鍵序判斷，不使用個別詞彙例外。

## 組字與編輯

- 未完成音節支援保守的注音順序修正：每類符號至多一個，原順序沒有有效單字讀音且重排後符合詞庫時才套用；不增刪注音、不改聲調、不跨越已完成或合法音節。Backspace 依原始按鍵順序退格。

- 支援左右移動、候選切換、插入、Backspace、Delete、Escape、Enter 與 Space。
- Delete 刪除游標右側，Backspace 刪除游標左側；只接受標準鍵碼，不另外提供刪除組合鍵或字元碼別名。
- 未完成音節時，Backspace 逐個刪除注音符號；Delete 保留目前音節，只刪除右側已完成的音節，右側為空則不變動。
- Home／End 可移到整段組字的開頭／結尾，保留正文與選字；若有未完成音節，先在原位置完成音節，不送出文字。
- 候選清單未開啟時，左右移動改變選字焦點並保留當下正文；上下鍵開啟清單後可循環切換候選。
- 候選清單開啟時，左右鍵及 Home／End 先確認目前候選，再移動游標；Escape 回復前一步組字操作，可撤回剛才的候選切換。
- 選字游標可設為靠左、靠右或「左右皆偵測 (準確率稍降)」。雙側模式交錯顯示兩側候選，選取後只替換該候選對應的範圍；句首與句尾自動使用存在的一側。
- 跨語言候選依原始按鍵對應的詞段範圍提供替代結果；可在游標附近的完整詞段邊界重新解讀中文或英文。預覽時標示替換範圍，確認後同步更新讀音及後方鎖定。
- 共用組字狀態保存每個已完成音節與未完成音節的來源按鍵；候選確認前比對來源範圍，來源已改變時不套用舊候選。
- 自動推測、候選預覽與人工確認分開記錄。自動合併不建立人工鎖定；新的注音輸入會解除自動決策，人工確認則保留到編輯交錯其範圍或再次選字。
- 中英自動合併只替換可精確對應本次來源按鍵的區段，保留前後內容；範圍無法對應或涵蓋人工確認詞段時，保留目前組字。
- 開啟候選時，先在原位置完成未完成音節，保留整段組字，不直接送出文字。
- 候選清單先確定順序再產生預覽，使顯示文字與選取索引一致。
- 確認後方詞彙時，未與鎖定範圍交錯的完整詞保留整句上下文。
- 在組字中間插入或刪除音節時，後方已確認詞彙的位置同步更新；編輯穿過的詞彙重新解碼，避免舊詞覆蓋新輸入或重複後段內容。
- 輸入新音節時，完整詞、功能字與助詞依詞庫證據比較，避免不必要的跨詞拆分。
- 提交後清除 raw buffer 與延遲重播狀態，避免舊組字再次出現。
- 人工確認只保護所選範圍，不把整段正文視為已確認；前後未選定的同音詞仍可能需要另行選字。
- 個人詞頻由明確選字累積，使用所選候選的語言、讀音與替換範圍；選取詞內單字不會誤記成整詞讀音，自動提交不視為使用者偏好。

## 標點與特殊符號

- Shift＋1～0 支援鍵盤對應的全形符號；標準美式鍵盤依序為「！＠＃＄％＾＆＊（）」，沿用組字與符號候選流程。

- 一般標點與 Shift 符號輸入都進入組字，保留在游標處，可繼續編輯。
- 支援 Shift 搭配數字列及標點鍵，例如 Shift+, 輸入「，」、Shift+. 輸入「。」、Shift+/ 輸入「？」。
- 符號可用 ↑／↓ 開啟同類候選，切換全形、半形及不同樣式；移動游標回到尚未送出的符號後也能重新選取。

## 詞庫擴充

- 教育部／萌典補充 85,922 筆中文詞目／讀音配對，Wikidata 補充 6,060 筆英文正式名稱與 4,609 筆別名對應。
- 英文名稱保留大小寫；別名與縮寫可提供對應正式名稱的候選。
- 中文只採用完整詞讀音，不逐字猜測專名讀音；既有詞條及權重保留，新增資料去重後以較低權重加入。
- 詞庫隨 app 打包，輸入時離線查詢；app 同時附上來源與授權說明。
- 匯入工具保留逐詞來源、版本與雜湊，支援重複執行而不累加相同資料。詳見 [開放詞庫說明](../lexicons/README.md)。
- 另有依官方來源整理的當代專有名詞，詳見 [詞彙來源](LEXICON_SOURCES.md)。

## 候選排序

- 中文候選尾端保留原注音選項，可選取並送出注音文字；沿用焦點詞段範圍與聲調，雙側及跨語言候選合併也保留此選項。

- 中文、英文、跨詞段及雙側候選共用合併規則：目前正文置頂，各來源按既有排序交錯提供候選；同名次、同起點優先完整替換範圍。
- 候選依文字、語言、替換範圍與重切讀音去重，來源標記不同不會重複列出；同字但替換效果不同的候選仍保留。焦點追蹤使用相同身分，避免補齊來源資訊時改選另一項。
- 各引擎先依自己的分數排序，再以候選名次合併；不直接相加中文、英文與其他來源的原始分數。個人詞頻可能改變候選名次。
- 明確輸入二、三、四聲或輕聲時，以完整讀音限制詞庫候選，不去除聲調，也不以其他聲調或近音補字；無對應詞條時保留原始讀音。未指定聲調時沿用補候選行為。
- 提供規則式排序與 Core ML 輔助，模型不可用時回退至規則式排序。
- 中文組字、選字窗及 MCP 預覽共用候選計分；個人 priority 只加入一次，不先依優先度改寫原始名次。
- 候選先評分再篩選，避免原始名次在第九名之後的常用詞無法參與自動組字。
- 完整詞依精確讀音與語料權重計分，不依完整詞個數或合併邊界重複給獎勵，也不僅因功能字身分施加固定獎懲。分詞後在固定範圍內使用左文輔助選詞。詳見 [計分機制](SCORING.md)。
- NN 對演算法產生的候選提供有界輔助；替代組字須依各自前文重算整句總分並優於原句，才會採用。
- 可獨立載入已訓練模型，無須重新編譯輸入法；舊模型保留原特徵格式，未知格式回退規則。詳見 [模型說明](../models/README.md)。
- 三聲「ㄧˇ」保留字詞候選，不被數字保護規則強制轉成「一」。

## 偏好設定

- HTML／CSS／JavaScript 介面搭配 Swift 設定橋接。
- 選字引擎目前僅支援「傳統優先＋AI 輔助」；其餘模式分組列為未支援，呈灰色且不可選取。
- 新安裝及不支援的舊設定統一使用已支援的引擎模式。
- 可調整候選游標對齊、停頓辨識及語言 target；停頓時間控制停止輸入後的中英合併辨識排程。
- 完整組字與選字診斷紀錄預設關閉，個人詞頻學習可獨立運作。
- 日文選項暫停開放，呈灰色且固定為「不使用」。
- 提供診斷分頁、版本資訊與 GitHub Release 更新檢查；關於卡片右側的「版本更新」按鈕依卡片高度垂直置中。

## macOS 整合

- 「版本更新」比對目前與 GitHub 最新正式 BUILD，確認後才下載相符架構的 DMG；通過校驗後自動啟動安裝程式，保留個人資料並重新載入輸入法。
- 更新期間顯示處理狀態並防止重複點擊；唯讀預覽不能下載或安裝。

- 提供一鍵安裝 DMG，開啟安裝程式後自動安裝至 `~/Library/Input Methods/全一輸入法.app`。
- 安裝程式與 DMG 磁碟使用全一輸入法圖示，發布封裝包含 Developer ID 簽章與 Apple 公證。
- 更新先備份舊版，失敗嘗試還原；保留個人詞頻與偏好設定。
- 候選 helper 與輸入法服務分開啟動，組字時才顯示內容。
- 啟動時預熱中文詞庫、候選排序與英文查詢。
- 建置支援指定架構、最低 macOS 版本、debug／release 及簽章選項。
- 根目錄 `build.command` 可建立可安裝 app；只有明確指定 `--deploy` 才更新本機。

## 目前限制

短句、缺少上下文及同音詞仍可能需要手動選字。跨語言重判以游標附近的既有完整詞段為範圍，尚不支援任意英文單字內部拆分。候選 helper 是過渡介面，與不同 macOS 編輯器的相容性仍持續改善。CLI 模擬器與原生事件的時序及游標行為也有差異，不能互相視為完整替代。
