# 組字與選字策略檢查、優化及修正

本文件保留該階段的歷史結果；最新累積狀態與測試環境請見 [五輪組字選字修正](組字選字五輪檢查與修正_20260921.md)。本機證據路徑不隨 GitHub 發布，歷史程式行號以當時檢查快照為準。

## 範圍與基準

本輪以已部署的混打邊界修正版為基準，檢查原始按鍵解析、未完成音節、詞段來源映射、混打區段、分詞圖、候選評分、人工選字鎖定、游標編輯、提交與測試隔離。

沒有變更介面資源、偏好選項、快捷鍵、選字操作、認證方式、簽署身分或權限需求。沒有更動詞庫內容、排序權重、模型特徵維度／契約或訓練模型。

## 已修正

### 第一聲末音節的整詞評估

混打解析器原先用尚未完成音節的預覽文字評分，第一聲末字未參與完整分詞，可能使中文區段輸給原始英文字母回退。例如「分析」在混打長句中被拆成 `zp 西`。

現在只在候選區段右邊界，使用完成音節的狀態副本評估整詞；逐鍵輸入來源狀態不變。既有未完成音節防護與人工確認邊界保留。相同原始按鍵的長句已恢復為「natural language processing 讓電腦可以分析 everyday language。」

### 選字左文被組字單位數截短

英文詞或展開文字可能只佔一個組字單位。原先取得候選左文時按單位數取字元前綴，`everybody` 因而變成 `e`，使候選評分的上下文與完整詞段不一致。

現在完整涵蓋的詞段保留全部文字；游標位於中文詞內時仍只取前綴。新增英文、多字候選、中文詞內及 UTF-16 游標驗證。

## 等價優化

- 分詞圖建立候選時，不再先做必然被丟棄的候選查詢；只在單音節無候選的回退分支才查詢。
- 無 Core ML 模型或傳統模式時，批次評分共用既有批次詞頻查詢，避免每個同音候選重新建立相同映射。
- 正式支援模式在無模型的隔離環境中，批次分數及排序與逐筆評分一致；模型推論分支未變更。不以並行測試耗時宣稱效能提升。

## 仍需處理的限制

- 同音詞語意判斷仍有限；不能由讀音單獨唯一決定文字。
- 英文縮寫及同時可解成合法中文音節的邊界仍有歧義，例如 `system` 後的中文首鍵被解成 `SystemC`。
- 長句測試尚未全數通過，測試保留原期望，未以詞句特例提高通過率。
- 原生探針模擬 IMK client，不能代表所有應用程式與實體鍵盤的完整整合測試。
