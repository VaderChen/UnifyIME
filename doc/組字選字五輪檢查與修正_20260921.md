# 組字與選字五輪檢查、優化及修正

## 範圍與結果

依要求接續完成五輪：每輪先以修改前程式重現問題，再修改共用規則並執行隔離策略 Smoke。介面、操作方式、快捷鍵、偏好選項與認證方式保持原樣；未調整詞庫內容、候選權重或模型契約，也未加入指定詞句的辨識特例。

本機已更新至 **1.26.0921 build 202609211907**；`bin/app` 與 `bin/cli` 已同步。正式版本建置、簽章、來源與成品雜湊、輸入來源、個人設定及安裝後 Smoke 均已比對。相關程式、測試與報告一併納入原始碼更新；此版號為本機驗證成品，本次不另建立 GitHub Release。

## 五輪修正

| 輪次 | 修改前可重現的問題 | 共用修正與驗證 |
| --- | --- | --- |
| 1：確認後前進 | 向右選字模式確認一詞後，游標移到下一詞尾，焦點因此跳過下一詞。 | 依既有游標模式選擇下一詞的起點或終點。左、右、雙側模式均只前進一詞；含既有控制項，9 通過／1 失敗 → 10／0。 |
| 2：重選與鎖定 | 先確認整詞，再重選詞內單字，舊整詞鎖定仍會覆蓋新選擇，並產生交疊確認範圍。 | 核心與原生控制器共用確認範圍替換規則，移除交疊舊鎖定，保存新選擇及未改動前後文。9／2 → 11／0。 |
| 3：個人詞頻保存 | 寫入失敗時提前清除待保存標記，無法重試；並行記錄及保存會競爭存取延遲工作項目，基準測試曾崩潰。 | 延遲工作項目在同一鎖內管理；磁碟保存序列化，只有成功保存且版本未再更新時才清除標記。失敗重試及並行計數驗證通過，含控制項為 9／0；另連續 10 次壓力測試，共 1,000 次選字記錄均完整保存。 |
| 4：候選快取 | 不同覆寫表的詞庫實例共用以讀音為鍵的全域快取，後建立的詞庫可能收到前一詞庫候選。 | 快取改隸屬不可變的詞庫實例，保留鎖定、512 筆容量與個人詞彙即時合併。交錯查詢保持各自候選順位；9／1 → 10／0。 |
| 5：詞內未完成音節 | 在多音節詞中間輸入注音，未完成音節被顯示到整詞後方；純數字保護路徑也可能漏掉未完成音節。 | 僅在呈現時按插入位置分開詞段，保留來源鍵位、確認狀態及所有剩餘文字。原有 3 項中失敗的 1 項修復，再加入已確認詞、原注音、多字候選與數字的插入／還原檢查，含控制項 18／0。 |

各輪策略數字包含相同的 7 項既有控制檢查，不能直接加總。最終一次整體策略執行共 **30／30** 通過。

隔離模式使用獨立資料並停用 Core ML 模型，與正式本機環境不同。「深綁」在隔離測試仍輸出「身榜」；正式本機環境的該案例通過，兩種環境皆已各自與修改前比對。正式及隔離環境皆保留「再檢查 → 在檢查」的組字／提交失敗，未修改測試期望。

長句測試與上一輪紀錄有 3 個未通過案例的文字不同，已用本輪修改前執行檔、相同隔離環境重跑這 3 個案例，結果均與修正後相同。這些差異不是本輪新增，沒有新增失敗案例；不以不同環境的耗時宣稱效能提升。

安裝後第一次額外探針使用了 CLI 不支援的 `home` 動作，工具明確拒絕；改用既有 `left`／`right` 動作重跑後 7／7 通過。CLI 左右鍵會先提交其模擬組字，安裝後這兩項只驗證文字插入及還原結果；原生未提交組字內的插入，以及 Home／End 行為，均以 316 個原生事件案例為依據。原始失敗探針紀錄保留供追查。

## 尚未消除的限制

同音詞的語意選擇，以及英文縮寫和合法注音鍵位之間的歧義，仍有既有失敗案例。五輪修正改善選字一致性、資料保存與組字編輯，並不表示所有長句辨識已達到全數正確。

隔離原生探針模擬 IMK client；安裝後探針執行實際安裝的程式，但不等同所有應用程式與實體鍵盤的全面整合測試。部署紀錄已核對中英切換設定前後一致，未改動硬體對應；實體按鍵須依 macOS 重新對應後的修飾鍵選擇。
