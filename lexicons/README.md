# 開放詞庫匯入

這個目錄記錄由教育部／萌典與 Wikidata 匯入的詞條來源。可載入資料位於既有的 `phrase_map.tsv` 與 `english_words.tsv`，因此一般 app 建置會一併打包，不需要另外連線查詞。

## 本次匯入

2026-09-08 匯入新增 **85,922 筆中文詞目／讀音配對**、**10,669 筆英文名稱／別名對應**。數量以查詢鍵與顯示文字配對計算，同一詞的不同讀音或別名可能各占一筆，不等同獨立詞目數。

一般建置會把本文件附於 app 的 `Contents/Resources/Lexicon-Licenses.md`，隨詞庫提供來源及授權標示。

## 資料與用途

- `imported_entries.jsonl`：逐詞記錄語言、查詢鍵、顯示文字、輸出行及來源。教育部詞條另外保留原始注音；Wikidata 詞條記錄 Q 編號。
- `import_manifest.json`：來源版本、下載檔案 SHA-256、分類、權重及匯入數量。
- 原始下載快照位於本機 `data/lexicon-import/`，不隨程式發布。這些資料用於詞庫轉換，不是 NN 訓練資料。

## 匯入規則

中文僅接受 2–8 字、字形完整，且具有逐音節完整詞讀音的詞條。注音空格移除，輕聲記號依引擎格式置於音節末尾，原始字形與讀音另存來源紀錄。不用單字讀音拼接猜測人名或品牌讀音。

英文以 Wikidata 的程式語言、軟體、作業系統、品牌、公司、上市公司、製造商及電子遊戲分類為來源。各分類取具有至少 5 個 Wikimedia 站點連結的條目，依站點連結數排序，最多 2,000 個項目；這是知名度篩選，不是實際輸入詞頻。保留英文名稱原有大小寫，以連續小寫鍵序查詢；英文別名及縮寫使用較低權重，候選顯示對應的正式名稱。目前英文引擎不接受數字等鍵序，這類名稱先不匯入，不擅自刪掉名稱中的數字或符號。

中文詞條與既有 common／phrase 字庫共同去重，英文以查詢鍵與顯示文字去重。既有詞條及權重不改寫；新增中文權重為 0，新增英文正式名稱權重為 200、別名為 150。這些權重只表示補充候選，並非語料統計頻率。

重編辭典含歷史詞彙，Wikidata 也可能收錄舊產品或歧義名稱。來源資料用來擴充覆蓋範圍，不保證所有輸入情境的首選都符合意圖。

## 重現匯入

在專案根目錄執行：

```sh
python3 scripts/import_lexicons.py --fetch
python3 scripts/import_lexicons.py --apply
```

第一個指令下載缺少的來源快照並預覽匯入數量，已有快照不覆寫；第二個指令寫入字庫與來源清單。重新執行會先辨識本工具前次輸出，不重複累加。前次匯入行若已被人工改動，工具會停止，避免覆蓋修改。

寫入前會建立 `.import.bak` 備份。確認本次字庫、來源清單與格式無誤後，再移除本次備份。更新上游資料時，應另存目前來源快照與 manifest，再下載新快照；完整資料版本以 manifest 的修訂號與雜湊為準。
